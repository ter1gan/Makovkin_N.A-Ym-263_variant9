# Лабораторная работа 1. Первые программы на Python

## Состав папки `lab01`

- `hello.py` — первая программа (подготовка).
- `profile.py` — обязательное задание 1: карточка студента.
- `workload.py` — обязательное задание 2: учебная нагрузка.
- `debug.py` — обязательное задание 3: поиск и исправление ошибок.
- `swap.py` — обязательное задание 4: обмен значениями.
- `variant.py` — индивидуальный вариант 9: «Магазин настольных игр».
- `README.md` — этот файл.

Откройте терминал в папке `lab01` и выполните:
