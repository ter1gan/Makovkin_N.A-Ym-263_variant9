# Лабораторная работа 5. Обработка строк

## Состав папки `lab05`

- `normalize.py` — обязательное задание 1: нормализация текста.
- `palindrome.py` — обязательное задание 2: палиндром через срез.
- `replace.py` — обязательное задание 3: замена с подсчётом.
- `variant.py` — индивидуальный вариант 9: «Не содержит букву `а`».
- `palindrome_loop.py` — дополнительно: палиндром без обратного среза.
- `README.md` — этот файл с проверками.

## Как запустить

Из папки `lab05`:

```bash
python normalize.py
python palindrome.py
python replace.py
python variant.py
python palindrome_loop.py
```

В Windows при отсутствии команды `python` используйте `py`.

## Проверки `variant.py` (вариант 9)

Условие варианта 9: слово **не содержит букву `а`** после очистки и приведения к нижнему регистру.

Контрольный текст из методички:

`Анна, армия! Я читаю. Книга, край, рама.`

После разбиения и очистки получаются слова:

`анна`, `армия`, `я`, `читаю`, `книга`, `край`, `рама`.

Букву `а` не содержит только `я`. Поэтому ожидается одно слово и количество `1`.

| № | Вход | Ожидание | Факт |
|---|---|---|---|
| 1 (контрольный текст) | `Анна, армия! Я читаю. Книга, край, рама.` | `я`, количество `1` | совпадает |
| 2 | `Анна, армия! Я читаю.` | `я`, количество `1` | совпадает |
| 3 (пустой ввод) | пустая строка | `Нет совпадений`, количество `0` | совпадает |
| 4 (только пунктуация) | `!!!` | `Нет совпадений`, количество `0` | совпадает |
| 5 (повторы) | `Я, я, ты` | `я`, `я`, `ты`, количество `3` | совпадает |
| 6 (слово с пунктуацией внутри) | `а!б, в` | `в` (у `а!б` есть `а`; `в` подходит), количество `1` | совпадает |

Пример вывода для контрольного текста:

```
я
Количество: 1
```

Пример вывода для `!!!`:

```
Нет совпадений
Количество: 0
```

## Дополнительно: `palindrome_loop.py`

Сравнение двух решений на одинаковых входах.

| Вход | `palindrome.py` (срез) | `palindrome_loop.py` (цикл) | Совпало? |
|---|---|---|---|
| `А роза упала на лапу Азора` | `Палиндром` | `Палиндром` | да |
| `а    ` | `Палиндром` | `Палиндром` | да |
| строка из пробелов | `Нет текста` | `Нет текста` | да |
| `Python` | `Не палиндром` | `Не палиндром` | да |
| `А!` | `Не палиндром` | `Не палиндром` | да |
| `шалаш` | `Палиндром` | `Палиндром` | да |
| `а, б, а` | `Не палиндром` | `Не палиндром` | да |

Оба решения дают одинаковый результат. В циклическом варианте важно идти по половине **очищенной** строки, а не исходной: иначе пробелы и регистр сломают сравнение.

## Краткие ответы

1. **Неизменяемость строк.** `text.lower()`, `text.replace(...)`, `text.strip()` возвращают **новую** строку и не меняют `text`. Поэтому результат нужно сохранять: `cleaned = text.lower().replace(" ", "")`.
2. **Слово и подстрока.** Слово — результат разбиения через `split()`; подстрока — любая часть строки, которую можно найти через `in` или `count()`. В варианте 9 проверяется именно слово после очистки, а не вся строка целиком.
3. **Пунктуация.** Правила обработки пунктуации нужно задать заранее: в `palindrome.py` пунктуация **сохраняется** и сравнивается, поэтому `А!` — не палиндром; в `variant.py` крайние `.,!?;:` **удаляются**, поэтому `Анна,` превращается в `анна`.
4. **Почему `range(a, b)` не всегда подходит** (из работы №4) — правый конец не включается; для включения нужен `b + 1`, для убывания — `b - 1` и шаг `-1`.
