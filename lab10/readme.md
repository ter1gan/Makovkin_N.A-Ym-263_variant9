## Формат `matrix.txt`

```
2 3
1 -2 3
4 0 -6
```

- Строка 1: два положительных целых — `R` (строки) и `C` (столбцы).
- Далее ровно `R` строк по `C` целых чисел.
- Пустые и лишние строки — ошибка. Один завершающий перевод строки допустим.

Для этого файла:

- суммы строк `[2, -2]`;
- суммы столбцов `[5, -2, -3]`;
- вариант 9 (последняя строка) → `-2`.

## Проверки из методички

| Ситуация | Ожидание | Факт |
|---|---|---|
| `1 2` / `7 -1` (пример из методички) | `[[7, -1]]` | совпадает |
| `1 1` и строка `0` | `[[0]]` | совпадает |
| Пустой файл | `ValueError` | совпадает |
| Заголовок `0 3` | `ValueError` | совпадает |
| Заголовок `1 2`, строка `1` | `ValueError` с указанием строки 2 | совпадает |
| Заголовок `1 2`, строка `1 x` | `ValueError` с указанием строки 2 | совпадает |
| Заголовок `1 1`, две строки данных | `ValueError` | совпадает |
| Отсутствующий путь | `FileNotFoundError` в функции; понятное сообщение в `main.py` | совпадает |

## Проверка сохранности `report.txt` (вручную)

1. Запускаю `main.py` на корректном `matrix.txt` — `report.txt` содержит три строки (см. пример).
2. Порчу `matrix.txt` (например, оставляю `2 3` и строку `1 -2` — не хватает одного числа во второй строке).
3. Снова запускаю `main.py`: программа печатает `Ошибка формата: Строка 2: ожидалось 3 чисел` и завершается.
4. Проверяю `report.txt` — содержимое **не изменилось**. Это и есть требование «при ошибке чтения или проверки входа существующий `report.txt` должен остаться без изменений».

Аналогично с отсутствующим файлом (`Файл не найден: matrix.txt`) и с файлом в другой кодировке (`Ошибка кодировки: ...`) — `report.txt` остаётся прежним.

## Ответы на вопросы 

**Ошибки формата vs ошибки доступа.**
- Формат — это «файл открылся, но содержимое не соответствует правилам»: пустой файл, заголовок `0 3`, в строке не хватает чисел, есть нечисловая ячейка, лишние/пустые строки. Это `ValueError`, его порождает `read_matrix` с указанием номера строки.
- Доступ — это «файл не удаётся открыть/прочитать/записать по причинам ОС»: файла нет (`FileNotFoundError`), нет прав (`PermissionError`), файл занят (`OSError`).
- Кодировка — отдельный случай (`UnicodeError`): файл открылся, но байты не декодируются как UTF-8. В `main.py` перехватывается отдельным `except UnicodeError` **до** `except ValueError`, потому что `UnicodeDecodeError` — частный случай `ValueError`.

**Почему отчёт открывается для записи только после проверки входа.** Режим `"w"` стирает прежнее содержимое файла в момент открытия. Если бы `report.txt` открывался «на всякий случай» до чтения и проверки матрицы, то при любой ошибке входа старый отчёт уже был бы уничтожен. Порядок в `main.py` такой: сначала прочитать и полностью проверить `matrix.txt`, посчитать все три величины, и только затем открыть `report.txt` для записи. Так при ошибке входа прежний отчёт сохраняется.
