## Задание 3. Запись и пара

```python
record = {"title": "Python", "hours": 4}
record["hours"] = 6
record["completed"] = False
pair = (record["title"], record["hours"])
name, hours = pair
```

Вывод: `Запись: {'title': 'Python', 'hours': 6, 'completed': False}`, `Пара: Python, 6`.

**Почему запись удобно представить словарём.** У записи есть именованные поля разных типов (`title` — строка, `hours` — число, `completed` — `bool`). Словарь хранит соответствие «имя поля → значение»: обращение по имени (`record["hours"]`), добавление нового поля одним присваиванием (`record["completed"] = False`), безопасное чтение отсутствующего поля через `get`. В списке или кортеже поля различаются только позицией, и порядок легко перепутать. Кортеж удобен для неизменяемой пары `(title, hours)`: распаковка `name, hours = pair` сразу даёт осмысленные имена.

## Вариант 9. Задания по программированию (`amount` — баллы)

`totals_by_category(records)` — сумма `amount` по категориям; `titles_in_category(records, category)` — названия в исходном порядке, неизвестная → `[]`. Записи не изменяются: в функциях только чтение.

### Общий набор из методички

| Проверка | Ожидание | Факт |
|---|---|---|
| `totals_by_category(records)` | `{"основное": 7, "дополнительное": 2}` | совпадает |
| `titles_in_category(records, "основное")` | `["A", "C"]` | совпадает |
| `titles_in_category(records, "нет")` | `[]` | совпадает |
| `totals_by_category([])` | `{}` | совпадает |
| `records == snapshot` | равно | равно |

### Пять записей варианта 9 (в `main()`)

| title | category | amount |
|---|---|---|
| Сумма чисел | базовые | 10 |
| Палиндром | строки | 15 |
| Словарь частот | словари | 20 |
| Фильтр списка | базовые | 12 |
| Проверка простоты | строки | 25 |

Три категории, две повторяются (`базовые`, `строки`). Сводка выводится **в алфавитном порядке** через `sorted(totals)`, категория для поиска вводится пользователем; неизвестная даёт `[]`.

## Краткие ответы

1. **Выбор структуры.** Словарь — для записи с именованными полями и для накопления сумм по категориям (`get`); множество — для уникальных тем и операций `&`/`|`; кортеж — для неизменяемой пары `(title, hours)` с распаковкой; список — для названий в исходном порядке.
2. **`.get()`.** `record.get("hours", 0)` возвращает значение по ключу или `0`, если ключа нет; прямой `record["hours"]` дал бы `KeyError`. В `totals_by_category` это позволяет добавить первую запись категории без проверки `if category not in totals`.
3. **Сортировка множества перед выводом.** У `set` нет гарантированного порядка, поэтому `sorted` даёт воспроизводимый вывод и позволяет сравнивать со списком в тестах.
