## Ответы на вопросы 

**Какую ошибку выявляет таблица 2×3.** На `[[1,2,3],[4,5,6]]` сумма строк имеет длину `2` (число строк), а сумма столбцов — длину `3` (число столбцов). Если перепутать индексы (`matrix[column][row]` вместо `matrix[row][column]`), `row_sums`/`column_sums` либо упадут с `IndexError`, либо вернут списки одинаковой длины — это сразу видно по ожидаемым `[6, 15]` и `[5, 7, 9]`.

**Почему нельзя повторять одну изменяемую строку.** `[[0] * 3] * 2` создаёт внешний список из двух ссылок на **один и тот же** внутренний список. `matrix[0][0] = 7` изменит обе «строки». `diagonal_pattern` создаёт новую строку в каждой итерации внешнего цикла, поэтому общей строки нет.

**Копия внешнего списка vs копирование строк.** `matrix.copy()` копирует только внешний список: элементы нового списка — те же внутренние списки, и изменение `copy[i][j]` меняет `matrix[i][j]`. `[row.copy() for row in matrix]` создаёт новые внутренние списки — это независимая копия таблицы чисел. `transform` возвращает полностью новую матрицу (внешний список и каждая строка новые), поэтому `result[0][0] = 999` не меняет `control`.
