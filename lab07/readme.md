## Проверки `select_numbers` (вариант 9)

Условие варианта 9: **от `0` до `threshold` включительно** (`0 <= value <= threshold`).

**Контрольный набор из методички:** `[-5, 0, 2, 5]`, порог `2` → ожидаемый результат `[0, 2]`.

| № | Вход `(numbers, threshold)` | Ожидание | Факт |
|---|---|---|---|
| 1 (контрольный набор) | `[-5, 0, 2, 5]`, `2` | `[0, 2]` | `[0, 2]` |
| 2 (пустой список) | `[]`, `5` | `[]` | `[]` |
| 3 (границы включены) | `[-1, 0, 1, 2, 3]`, `2` | `[0, 1, 2]` | `[0, 1, 2]` |
| 4 (нет совпадений) | `[-3, -1, 5, 6]`, `2` | `[]` | `[]` |
| 5 (`threshold = 0`) | `[-2, 0, 2]`, `0` | `[0]` | `[0]` |
| 6 (повторы) | `[1, 1, 2, 2, 0, 0]`, `2` | `[1, 1, 2, 2, 0, 0]` | `[1, 1, 2, 2, 0, 0]` |
| 7 (исходный не изменён) | `[5, 3, 0, -1]`, `4` | исходный `[5, 3, 0, -1]` | `[5, 3, 0, -1]` |

Проверки границ: `0` включается (`0 <= value`), `threshold` включается (`value <= threshold`). Значения `-1` и `3` при `threshold = 2` не попадают. Повторы сохраняются, порядок — как во входном списке. Исходный список не изменяется (`numbers == snapshot` в `test_functions.py`).

## Демонстрация обнаружения ошибки

Если в `select_numbers` заменить условие на `0 < value <= threshold` (исключить `0`), то проверка

```python
assert select_numbers([-5, 0, 2, 5], 2) == [0, 2]
```

падает: функция возвращает `[2]`, ожидание `[0, 2]`. Проверка ловит ошибку на границе. После возврата `0 <= value <= threshold` все проверки снова проходят.

## Краткие ответы

1. **Возврат и вывод.** `return` возвращает значение **вызывающему коду** и завершает функцию; `print` только **показывает** текст человеку и ничего не передаёт. В `functions.py` нет `print`, потому что эти функции должны использоваться и в `main.py`, и в тестах. В `main.py` результат `average(numbers)` используется в `if avg is None`, а не берётся из вывода.
2. **Локальная переменная и параметр.** Параметр — имя из заголовка `def`, значение ему присваивается при вызове. Локальная переменная создаётся внутри тела. Оба видны только внутри функции. Изменение параметра (например, `number = abs(number)` в `sum_digits`) не влияет на переменную в вызывающем коде.
3. **`average` возвращает `None`, а не печатает.** Это делает функцию пригодной и для тестов, и для `main.py`, где оформление «Нет данных» — решение уровня интерфейса. Если бы `average` печатала, тест `average([]) is None` был бы невозможен, а `main.py` не смог бы решить, что выводить.
4. **`assert` и проверка пользовательского ввода.** `assert` — для **учебных проверок функций** внутри `test_functions.py`. Для проверки пользовательского ввода в `main.py` используется `if/else` и явные сообщения (как в предыдущих работах), потому что при оптимизированном запуске (`python -O`) `assert`-ы отключаются.
5. **Почему тест с `0` важен.** Вариант 9 включает `0`; замена `0 <= value` на `0 < value` формально «почти верна», но именно на нуле и на `threshold` она ломается. Проверка `select_numbers([-5, 0, 2, 5], 2) == [0, 2]` ловит такую ошибку.
