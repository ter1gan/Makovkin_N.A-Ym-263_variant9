```bash
python statistics.py
python transform.py
python positions.py
python variant.py
python dedup.py
```

В Windows при отсутствии команды `python` используйте `py`.

## Краткие ответы

1. **`append()` и присваивание по индексу.**
   - `items.append(value)` **добавляет** новый элемент в конец; длина списка увеличивается на 1.
   - `items[i] = value` **заменяет** существующий элемент по индексу `i`; длина не меняется. Если индекс выходит за диапазон — `IndexError`.
2. **`sorted()` и `sort()`.**
   - `sorted(items)` возвращает **новый** отсортированный список, исходный не меняется. Поэтому в `variant.py` можно вывести и `selected`, и `ordered` одновременно.
   - `items.sort()` сортирует список **на месте** и возвращает `None`. Поэтому `ordered = items.sort()` дал бы `None`, а не список.
3. **Исходный список сохранён (задание 2).** `transform.py` строит `transformed` с нуля через `append`; к `original` не применяется ни `[i] = ...`, ни `sort`, ни `pop`. Поэтому после вывода исходный список совпадает с введённым.
4. **Пустой ввод.** В `statistics.py` ветка `if not numbers` не даёт вызвать `min([])`/`max([])` и делить на ноль. В `variant.py` пустой ввод сразу даёт `[]`, `0`, `0`, `[]` — без особой ветки, потому что `len([]) = 0`, `sum([]) = 0`, `sorted([]) = []`.
5. **`enumerate` в `positions.py`.** Даёт пары «индекс, значение» и позволяет одновременно сравнивать значение с максимумом и сразу собирать индексы в правильном (возрастающем) порядке, без второго прохода по `range(len(numbers))`.
